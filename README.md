One word describing my boss: **asap**.

Every boss has a catchphrase, and this one is his whole personality: everything is
ASAP, nothing has a real deadline, and the urgency never switches off. The word is
the entry — four letters, no caption, no explanation.

## How it works

`main.py` copies the pre-written `entry.txt` into the output directory
(`MAKEFUN_OUTPUT_DIR`, default `output/`). It uses only the Python standard
library, so it runs the same way in the grader's sandbox.

## Files

- `entry.txt` — the entry, one word: `asap`
- `main.py` — stdlib-only copier that writes `entry.txt` to the output directory
- `LICENSE` — MIT
